01

How to use this guide

Each AI prompt below has two parts: the subject prompt (what is in the picture) and the house style (how it looks). Paste both, in that order, into Midjourney, DALL·E / ChatGPT, Firefly, Ideogram or similar. Always add the negative prompt where the tool supports it.

Workflow

  • Find the slot in the master list (section 03).
  • If it is marked AI, copy its prompt from section 04 and add the house style.
  • Set the aspect ratio in the tool (e.g. Midjourney --ar 4:5), then upscale or export at the listed pixel size.
  • Save as JPG or WebP, sRGB, using the exact file name given.
  • Upload to public/images/ on GitHub and tell the developer; they connect it and optimise it.

Must be real photographs

  • Dr. Niaz himself: portraits, on-set and lecture photos.
  • Real people: guests, cricketers, guest authors.
  • Book covers: the actual published covers.
  • Memorabilia items: the captions name real pieces, so the photos must show those pieces.

AI images of real people, or of objects presented as genuine, would mislead visitors and can damage his credibility. Use AI only for mood and illustration, as marked.

House style · add to the end of every promptcinematic editorial photograph, warm sepia monochrome colour grade, deep brown-black background (#120f0c), soft single key light from the side, subtle amber (#e8711c) rim light accent, shallow depth of field, fine film grain, quiet minimal composition with generous negative space, premium magazine quality, photorealistic, no text
Negative prompt · use where supportedtext, letters, numbers, captions, logos, watermarks, brand names, team crests, sponsor marks, faces, recognisable people, celebrities, hands with extra fingers, distorted anatomy, cluttered background, oversaturated colours, neon, cartoon, illustration, 3D render, plastic look, HDR halo

Export settings

  • JPG quality 85 or WebP quality 82, sRGB.
  • Under ~600 KB per file; the site re-compresses anyway.
  • Keep the main subject in the centre 60%: the site crops differently on phones and desktops.
  • No text in images: titles are added by the website.

Tool tips

  • Midjourney: add --ar 4:5 --style raw --v 7 (change the ratio per slot) and put the negatives after --no.
  • ChatGPT / DALL·E: say “aspect ratio 4:5, portrait” in words and repeat “no text, no people”.
  • Firefly: Content type Photo, Visual intensity low, and upload the home banner as a Style reference.

Uploading

  • Upload page: github.com/Rajwara/Dr-Numan-/upload/claude/determined-hypatia-1fja1q/public/images
  • Use the file names in this guide, all lower-case, with hyphens and no spaces.
  • Send the developer a short note listing what was uploaded.

Matching the look

  • For real photos, apply a warm sepia grade (Lightroom: saturation −70, warm white balance, slight fade in the blacks) so they sit with the AI images.
  • Keep backgrounds dark and uncluttered.
  • Keep the subject centred: every slot is cropped slightly differently on phones.
